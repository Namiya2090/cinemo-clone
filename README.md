# 🎬 Cinemo Clone

HTML, CSS, Git을 사용해 구현한 가상의 OTT 웹사이트 클론 프로젝트입니다.

🔗 **배포 링크**: [Cinemo Clone 바로가기](https://namiya2090.github.io/cinemo-clone/)

---

## 🛠 사용 기술 (Tech Stack)

- **Markup**: HTML5
- **Styling**: CSS3 (Responsive Web, `clamp()`, `vw`)
- **Version Control**: Git / GitHub Pages (배포)

---

## ✨ 주요 기능 및 특징

- **멀티 페이지 구성**: 메인, 마이페이지, 프로필 페이지 간 유기적인 이동 지원
- **반응형 웹 디자인**: `clamp` 함수, `vw` 단위, 미디어 쿼리를 활용하여 다양한 디바이스 환경 대응
- **UI 인터랙션**: 마우스 호버 효과, 탭 메뉴 등 직관적인 사용자 인터랙션 구현

---

## 🧭 페이지 이동 가이드

- **메인 페이지**: 상단의 `cinemo` 로고 또는 `홈` 네비게이션 메뉴 클릭
- **마이페이지**: 메인 페이지 우측 상단의 `마이페이지` 링크 클릭
- **프로필 페이지**: 마이페이지 내 `프로필 변경` 버튼 클릭
- **메인으로 복귀**: 프로필 페이지 내 `욜로 프로필` 클릭 시 메인 페이지로 이동

---
